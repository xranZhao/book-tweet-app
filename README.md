# 推文助手

手机 PWA：选书 → 完整阅读 → 决定是否生成推文 → 编辑 → 云上传。

## 使用

- 设置中填写 DeepSeek API Key。默认阅读模型 `deepseek-flash`，写作模型 `deepseek-v4-pro`。
- 导入 TXT、Markdown、EPUB 或 ZIP。ZIP 读取最大的 TXT/Markdown 文件。
- 每约 5 万字符读一段；逐段保存笔记，全部完成后汇总剧情与看点。关闭页面会中断当前请求，重新打开可以继续已保存的进度。长篇阅读时请保持页面打开。
- 点击生成后才调用写作模型，输出不超过 800 字；可以直接修改标题、正文，文字自动保存在本设备。
- 云上传沿用阿野收件箱的 GitHub Contents API。填写同一个 GitHub Token、仓库和目录，默认 `xranZhao/aye-article-inbox` 的 `0-原始文稿`。上传的是编辑后的 Markdown；同一稿件再次上传前确认覆盖。电脑端继续使用阿野工作流下载处理。
- 排版不在 PWA 内，原有排版脚本与风格指南保留。

## 数据与费用

正文、笔记、草稿使用 IndexedDB；首次打开迁移旧版草稿与历史，旧 localStorage 数据不删除。历史可打开编辑。清除网站数据会删除本地内容；云上传成功的稿件保存在 GitHub。

费用预估使用中文字符约 0.6 token，仅供参考。记录接口实际 token 用量，并按内置单价估算人民币费用；未接入节假日日历，节假日高峰估值可能偏高，以 DeepSeek 账单为准。模型使用非思考模式控制费用，不自动重试收费请求。分段笔记可能遗漏细节，不等同于逐字准确的专业审校。

## 验证

使用现有 Chrome 与 Playwright 模拟接口验证：长篇分段覆盖、失败后断点恢复、刷新保留进度、编辑自动保存、Markdown 上传与旧数据迁移。未消耗真实模型余额或写入真实云端测试稿。
